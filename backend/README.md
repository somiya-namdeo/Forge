# Forge Backend

The AI core of Forge. Responsible for knowledge ingestion, retrieval, reasoning, and generation of AI system architectures.

## Modules

- `app/api/`: REST endpoints.
- `app/ingestion/`: Parses documents.
- `app/retrieval/`: Vector search.
- `app/reranking/`: Relevance enhancement.
- `app/reasoning/`: Logic synthesis.
- `app/generation/`: LLM generation.
