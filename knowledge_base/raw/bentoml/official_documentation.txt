<section id="what-is-bentoml">
<h2>What is BentoML<a class="headerlink" href="#what-is-bentoml" title="Link to this heading">¶</a></h2>
<p>BentoML is a <strong>Unified Inference Platform</strong> for deploying and scaling AI models with production-grade reliability, all without the complexity of managing infrastructure. It enables your developers to <strong>build AI systems 10x faster with custom models, scale efficiently in your cloud, and maintain complete control over security and compliance</strong>.</p>
<img alt="The architecture diagram of the BentoML unified inference platform" src="_images/bentoml-inference-platform.png" />
<p>To get started with BentoML:</p>
<ul>
<li><p>Use <a class="reference external" href="https://pip.pypa.io/en/stable/installation/">pip</a> to install the <a class="reference external" href="https://github.com/bentoml/BentoML">BentoML open-source model serving framework</a>, which is distributed as a Python package on <a class="reference external" href="https://pypi.org/project/bentoml/">PyPI</a>.</p>
<div class="highlight-bash notranslate"><div class="highlight"><pre><span></span><span class="c1"># Recommend Python 3.9+</span>
pip<span class="w"> </span>install<span class="w"> </span>bentoml
</pre></div>
</div>
</li>
<li><p><a class="reference external" href="https://www.bentoml.com/">Sign up for BentoCloud</a> to get a free trial.</p></li>
</ul>
</section>
