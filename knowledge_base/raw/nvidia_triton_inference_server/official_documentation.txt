<section class="tex2jax_ignore mathjax_ignore" id="nvidia-triton-inference-server">
<h1>NVIDIA Triton Inference Server<a class="headerlink" href="#nvidia-triton-inference-server" title="Link to this heading">#</a></h1>
<p>Triton Inference Server is an open source inference serving software that streamlines
AI inferencing. Triton Inference Server enables teams to deploy any AI model from multiple deep
learning and machine learning frameworks, including TensorRT, PyTorch,
ONNX, OpenVINO, Python, RAPIDS FIL, and more. Triton supports inference
across cloud, data center, edge and embedded devices on NVIDIA GPUs, x86 and ARM
CPU, or AWS Inferentia. Triton Inference Server delivers optimized performance
for many query types, including real time, batched, ensembles and audio/video
streaming. Triton inference Server is part of
<a class="reference external" href="https://www.nvidia.com/en-us/data-center/products/ai-enterprise/">NVIDIA AI Enterprise</a>,
a software platform that accelerates the data science pipeline and streamlines
the development and deployment of production AI.</p>
  <!-- :::
  :align: center
  [![Getting Started Video](https://img.youtube.com/vi/NQDtfSi5QF4/1.jpg)](https://www.youtube.com/watch?v=NQDtfSi5QF4)
  ::: -->
<div>
<iframe width="560" height="315" src="https://www.youtube.com/embed/NQDtfSi5QF4" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>
</div>
<section id="triton-architecture">
<h2>Triton Architecture<a class="headerlink" href="#triton-architecture" title="Link to this heading">#</a></h2>
<p>The following figure shows the Triton Inference Server high-level
architecture. The <a class="reference internal" href="user_guide/model_repository.html"><span class="std std-doc">model repository</span></a> is a
file-system based repository of the models that Triton will make
available for inferencing. Inference requests arrive at the server via
either <a class="reference internal" href="customization_guide/inference_protocols.html"><span class="std std-doc">HTTP/REST or GRPC</span></a> or by the <a class="reference internal" href="customization_guide/inprocess_c_api.html"><span class="std std-doc">C
API</span></a> and are then routed to the appropriate per-model
scheduler. Triton implements <a class="reference internal" href="user_guide/architecture.html#models-and-schedulers"><span class="std std-ref">multiple scheduling and batching
algorithms</span></a> that can be configured on a
model-by-model basis. Each model’s scheduler optionally performs
batching of inference requests and then passes the requests to the
<a class="reference internal" href="backend/README.html"><span class="std std-doc">backend</span></a>
corresponding to the model type. The backend performs inferencing
using the inputs provided in the batched requests to produce the
requested outputs. The outputs are then returned.</p>
<p>Triton supports a <a class="reference internal" href="backend/README.html#triton-backend-api"><span class="std std-ref">backend C
API</span></a>
that allows Triton to be extended with new functionality such as
custom pre- and post-processing operations or even a new deep-learning
framework.</p>
<p>The models being served by Triton can be queried and controlled by a
dedicated <a class="reference internal" href="user_guide/model_management.html"><span class="std std-doc">model management API</span></a> that is
available by HTTP/REST or GRPC protocol, or by the C API.</p>
<p>Readiness and liveness health endpoints and utilization, throughput
and latency metrics ease the integration of Triton into deployment
framework such as Kubernetes.</p>
<p><img alt="Triton Architecture Diagram" src="_images/arch.jpg" /></p>
</section>
<section id="triton-major-features">
<h2>Triton major features<a class="headerlink" href="#triton-major-features" title="Link to this heading">#</a></h2>
<p>Major features include:</p>
<ul class="simple">
<li><p><a class="reference internal" href="backend/README.html#where-can-i-find-all-the-backends-that-are-available-for-triton"><span class="std std-ref">Supports multiple deep learning
frameworks</span></a></p></li>
<li><p><a class="reference external" href="https://github.com/triton-inference-server/fil_backend">Supports multiple machine learning
frameworks</a></p></li>
<li><p><a class="reference internal" href="user_guide/model_execution.html#concurrent-model-execution"><span class="std std-ref">Concurrent model
execution</span></a></p></li>
<li><p><a class="reference internal" href="user_guide/batcher.html#dynamic-batcher"><span class="std std-ref">Dynamic batching</span></a></p></li>
<li><p><a class="reference internal" href="user_guide/batcher.html#sequence-batcher"><span class="std std-ref">Sequence batching</span></a> and
<a class="reference internal" href="user_guide/implicit_state_management.html#implicit-state-management"><span class="std std-ref">implicit state management</span></a>
for stateful models</p></li>
<li><p>Provides <a class="reference external" href="https://github.com/triton-inference-server/backend">Backend API</a> that
allows adding custom backends and pre/post processing operations</p></li>
<li><p>Model pipelines using
<a class="reference internal" href="user_guide/ensemble_models.html#ensemble-models"><span class="std std-ref">Ensembling</span></a> or <a class="reference internal" href="user_guide/bls.html#business-logic-scripting"><span class="std std-ref">Business
Logic Scripting
(BLS)</span></a></p></li>
<li><p><a class="reference internal" href="customization_guide/inference_protocols.html"><span class="std std-doc">HTTP/REST and GRPC inference
protocols</span></a> based on the community
developed <a class="reference external" href="https://github.com/kserve/kserve/tree/master/docs/predict-api/v2">KServe
protocol</a></p></li>
<li><p>A <a class="reference internal" href="customization_guide/inprocess_c_api.html"><span class="std std-doc">C API</span></a> and
<a class="reference internal" href="customization_guide/inprocess_java_api.html"><span class="std std-doc">Java API</span></a>
allow Triton to link directly into your application for edge and other in-process use cases</p></li>
<li><p><a class="reference internal" href="user_guide/metrics.html"><span class="std std-doc">Metrics</span></a> indicating GPU utilization, server
throughput, server latency, and more</p></li>
</ul>
<p>Join the <a class="reference external" href="https://www.nvidia.com/en-us/deep-learning-ai/triton-tensorrt-newsletter/">Triton and TensorRT community</a> and stay current on the latest product updates, bug fixes, content, best
practices, and more. Need enterprise support? NVIDIA global support is available
for Triton Inference Server with the <a class="reference external" href="https://www.nvidia.com/en-us/data-center/products/ai-enterprise/">NVIDIA AI Enterprise software suite</a>.</p>
<p>See the <a class="reference external" href="https://docs.nvidia.com/deeplearning/triton-inference-server/release-notes/">Latest Release Notes</a> for updates on the newest features and bug fixes.</p>
